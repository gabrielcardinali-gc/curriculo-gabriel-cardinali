# Currículo executivo - Gabriel Cardinali

Projeto estático em HTML/CSS para apresentar o perfil executivo de Gabriel Cardinali em uma página pública, responsiva e orientada a resultados.

A proposta é funcionar como uma vitrine profissional para posições de liderança em projetos, processos, PMO, transformação operacional, eficiência, governança, BPM, IA e RPA, mantendo uma linguagem sóbria, objetiva e adequada a posições sênior, head e diretoria.

## Arquivos

- `index.html`: versão web executiva.
- `ats.html`: versão simplificada para leitura por ATS e envio direto a recrutadores.
- `styles.css`: estilos principais para tela.
- `print.css`: ajustes para impressão e exportação em PDF.

## Como visualizar localmente

Abra `index.html` diretamente no navegador.

Para gerar PDF:

1. Abra `index.html` ou `ats.html` no navegador.
2. Use `Ctrl + P`.
3. Selecione "Salvar como PDF".
4. Revise margens, quebras de página e escala antes de salvar.
