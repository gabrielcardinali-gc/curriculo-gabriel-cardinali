# Curriculo executivo - Gabriel Cardinali

Projeto estatico em HTML/CSS para apresentação do meu perfil executivo.

## Tópicos
- currículo / resume
- portfólio
- pmo
- bpm
- process-improvement
- operational-excellence
- lean-six-sigma

## Arquivos

- `index.html`: versao web executiva, responsiva e visual.
- `ats.html`: versao simplificada para leitura por ATS.
- `styles.css`: estilos principais para tela.
- `print.css`: ajustes para impressao/exportacao em PDF.
- `assets/gabriel-cardinali-cv.pdf`: PDF original usado como referencia.

## Como visualizar

Abra `index.html` diretamente no navegador. Para gerar PDF, use a opcao de impressao do navegador e selecione "Salvar como PDF".
